# 📱 FinWise Mobile - Ultra-Fast Expense & Balance App

Yeh app khas taur par **Mobile Phone ke liye design ki gayi hai** taki aapko transaction entry karne me bilkul bhi deri na ho (**entry sirf 2 se 3 seconds me ho jati hai**).

---

## 📲 Mobile Phone Par Kaise Kholein?

Aapka phone aur computer ek hi Wi-Fi se connected hain:

1. Computer terminal me command chalayein:
   ```bash
   npm start
   ```
2. Apne **Mobile Phone ke Chrome ya Safari browser** me ye link kholein:
   👉 **`http://10.143.203.177:3000`**

### 💡 Mobile Par Native App Jaisa Chalayein (Add to Home Screen):
Jab aap apne phone ke Chrome browser me ye link kholein:
- Chrome ke **3 dots (Menu)** par click karein.
- **"Add to Home screen"** (या **"Install App"**) par tap karein.
- Ab aapke phone ke home screen par ek app icon ban jayega! Is par tap karne se yeh bina browser address bar ke full-screen native Android app ki tarah chalega.

---

## ⚡ Super-Fast Entry (3 Seconds Me Kaise Hogi?)

1. Bottom bar me beech wale **`+ FAST ADD`** button par tap karein.
2. **Amount** daalein (ya niche diye `+₹100`, `+₹500`, `+₹1,000` pills par tap karein).
3. **Account** chunein (`[SBI]`, `[CBI]`, `[BOB]`, `[Kotak]`, `[Cash Wallet]`).
4. **Category Tile** par 1-tap karein (🛒 Ration, 🍔 Khana, ⛽ Petrol, 💡 Recharge, 📈 SIP). Category tap karte hi Description apne aap fill ho jata hai — **typing karne ki zaroorat nahi padti**!
5. **`[ ⚡ JODEIN ]`** par tap karein.
👉 Account se balance turant kat jayega aur live update ho jayega!
